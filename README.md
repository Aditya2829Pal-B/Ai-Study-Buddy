# Neural Learn

A premium, full-stack, AI-powered study toolkit built with React, Vite, Express, and Socket.IO.

## Features
- **AI Material Generation**: Uses Gemini 3.5 Flash to automatically generate syllabus-mapped roadmaps, practice questions, and flashcards.
- **Collaborative Study Spaces**: Real-time WebSockets powered whiteboard, rich-text notes, and live WebRTC voice chat.
- **Pro Tier Subscription**: Integrated Stripe portal simulation and pricing tables.
- **Persistent Storage**: Robust data schema persisting user uploads, materials, and collaboration states locally.
- **Analytics & History**: Beautiful dashboard rendering activity streaks, hours tracking, and history logs.

## Setup
```sh
npm install
npm run build
npm run start
```
