# AI Study Buddy

AI Study Buddy is a full-stack collaborative learning platform that combines real-time teamwork with AI-powered study assistance. Students can collaborate through shared notes, interactive whiteboards, live chat, and voice communication while leveraging AI to generate study materials, summaries, and learning guidance.

## ✨ Features

### 🤝 Real-Time Collaboration

* Live collaborative note-taking
* Multiplayer whiteboard
* Real-time chat messaging
* Active user presence indicators
* Instant synchronization using Socket.io

### 🎙️ Voice Communication

* Peer-to-peer voice calls using WebRTC
* Low-latency audio communication
* Collaborative study sessions

### 🤖 AI-Powered Learning

* Intelligent study assistant
* AI-generated study materials
* Topic-based learning support
* Syllabus-driven content generation
* Context-aware academic assistance

### 🎨 Modern User Experience

* Responsive interface
* Smooth animations with Framer Motion
* Clean and intuitive design
* Optimized collaborative workflow

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+)
* npm or yarn
* Gemini API Key

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/ai-study-buddy.git

# Navigate to project
cd ai-study-buddy

# Install frontend dependencies
npm install

# Install backend dependencies
cd server
npm install
```

### Environment Variables

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
PORT=5000
```

### Run the Application

```bash
# Backend
npm run server

# Frontend
npm run dev
```
